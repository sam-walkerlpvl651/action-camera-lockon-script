## What It Does

Action Camera Lock-On is built for Minecraft 1.21.1 on NeoForge and runs on the client side. Its camera lock-on and entity-tracking tools assist with keeping the view aligned to a chosen target during play.

Targeting can be handled through Smart Lock or Always-Lock behavior. The mod can evaluate nearby entities, filter for hostile targets, and check line of sight before selecting or validating a target. A 3D reticle identifies the entity currently being tracked.

---

## Included Features

- Smoothly guides the camera toward a locked entity
- Provides Smart Lock with adjustable tracking behavior
- Offers Always-Lock for continuous target selection
- Allows the active target to be changed while tracking
- Prioritizes targets according to proximity
- Filters target candidates by hostility
- Checks line of sight during target evaluation
- Renders a 3D reticle around the current target
- Includes an in-game settings interface
- Supports configurable keybinds for mod controls

## Configuration

The mod exposes the following settings and behaviors:

| Option | Purpose |
| --- | --- |
| Smart Lock | Enables the mod's smart target-locking behavior. |
| Always-Lock | Keeps the chosen lock-on behavior active. |
| Target Switching | Selects a different entity to track. |
| Proximity Priority | Gives preference to targets that are closer. |
| Hostile Entity Filter | Restricts selection to hostile entities. |
| Line of Sight | Checks visibility while targets are being assessed. |
| 3D Target Reticle | Displays an in-game marker on the tracked entity. |
| Keybinds | Sets the controls used by the mod. |

Open the in-game configuration UI to change supported options and inspect the current key assignments.
